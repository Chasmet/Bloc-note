## Défaut diagnostiqué dans la version 50024
La capture utilisateur affiche `Produit d'achat unique non disponible sur Google Play.`. Le code antérieur exigeait `ProductDetails.getOneTimePurchaseOfferDetailsList()` non null et non vide. D'après les références officielles Google, cette liste peut être absente sur les produits uniques classiques ; `ProductDetails.getOneTimePurchaseOfferDetails()` fournit alors l'offre unique rétrocompatible.

## Correctif appliqué
`PlayBillingController.java` : ajout de `purchaseOffer()` qui préfère la liste des offres éligibles, puis utilise l'offre unique classique en secours. `ready()`, l'affichage du prix et `buy()` partagent désormais cet accès. Le message d'indisponibilité distingue un code de réponse non OK d'un produit/offre non retourné.
Identité préservée : package `com.sync30.mesnotesdossiers` ; Google Play Billing `9.1.0` ; achat non consommable product ID `blocnote_premium_lifetime` ; signature conservée ; aucune migration/désinstallation de données.
